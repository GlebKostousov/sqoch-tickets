# Оформление билетов Sqoch

Демонстрационный экран покупки билетов. Стек совпадает с фронтендом ТАКТ: SvelteKit, Svelte 5, TypeScript в строгом режиме.

Инструкция для проверки человеком — `README.md`. Как устроен код — `docs/decisions.md`. Куда смотреть в документах — `docs/dev-control.md`.

## Что перенесено из ТАКТ

- Пакет фичи и один публичный вход: `src/lib/features/checkout`.
- Страница только собирает экран и не хранит правила заказа.
- Страж импортов: `npm run check:import-budget`. Лимит страницы — 15 строк `import`. Внутренние файлы с «_» снаружи пакета не импортируются.
- Имена и email живут в памяти одной вкладки. В `localStorage` их нет.
- Повтор подтверждения с тем же ключом не создаёт второй заказ.
- Описания модулей и функций — на русском.
- Проверка перед сдачей: `npm run verify`, затем браузерные сценарии `npm run test:e2e`.

## Что в этот репозиторий не входит

Сервер, база, авторизация, общий кэш списков и сайт документации. Задание — один экран на моковых данных. Причины записаны в `docs/decisions.md`.
